# MeMeMe SFX pack — MVP 0.1.36

User-supplied event cues normalized to compact Ogg/Opus for browser playback.

- `victory.ogg` — final match result
- `news.ogg` — News event
- `card.ogg` — card draw
- `step.ogg` — each movement step
- `money_loss.ogg` — B$ loss
- `money_gain.ogg` — B$ gain (corrected source supplied 2026-09-14)
- `dice.ogg` — D6 roll, including Roll For Order
- `choice.ogg` — menu/picker confirmation

Mini Game BGM is **not** part of this SFX pack. Mini Games reuse the existing locked `03_City_Silly.ogg` BGM.
